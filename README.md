# Lineage Sprite Studio V2.2

리니지 1 클라이언트의 `Sprite00.idx/pak ~ Sprite15.idx/pak` 전체를 검색해서 특정 GFX의 동작 SPR을 자동으로 찾아 교체하는 Windows 도구입니다.

## V2.2 핵심 변경

- 선택한 IDX 하나만 보는 방식 제거
- Sprite00~Sprite15 전체 자동 검색
- `파일명 bytes 합계 % 16` 기준 실제 Sprite PAK 분배 검사
- `61-0.spr`, `61-1.spr` ... 각 동작을 실제 들어 있는 PAK에서 교체
- PNG 파일명에서 동작 번호/프레임 번호를 직접 읽어 잘못된 순서 삽입 방지
- 원본 SPR의 프레임 수와 새 PNG 프레임 수가 다르면 적용 중단
- PAK 전체 재작성 대신 새 SPR을 끝에 append하고 IDX offset/size 갱신
- 적용 직후 다시 추출해서 SHA-256 비교. 하나라도 다르면 성공 처리하지 않음
- 실패 시 IDX 복원 + PAK 원래 길이로 자동 rollback
- 0~100% 애니메이션 진행 바, 현재 작업, 처리 개수, 경과시간 표시

## PNG 이름 규칙

예:

- `61-0Wframe_000.png`
- `61-0Wframe_001.png`
- `61-1Wframe_000.png`

즉 `GFX-동작번호 ... frame_프레임번호.png` 형식이면 됩니다.

## 사용 순서

1. 게임 클라이언트를 완전히 종료합니다.
2. 클라이언트 폴더를 선택합니다.
3. GFX 번호를 입력합니다. 기사 남자는 현재 확인 기준 61입니다.
4. 새 PNG 프레임 폴더를 선택합니다.
5. **GFX 전체 검색**을 누릅니다.
6. 원본 프레임 수와 새 PNG 수가 모두 맞는지 표에서 확인합니다.
7. **백업 후 클라이언트에 적용**을 누릅니다.
8. 프로그램이 적용 후 재추출/해시 검증까지 100% 완료한 뒤 게임을 실행합니다.

## 안전장치

적용 전 복구용 백업을 켜면 클라이언트 폴더 아래에 `SpriteStudio_Backup_날짜시간` 폴더가 만들어집니다.
PAK는 수백 MB라 통째로 복사하지 않고, IDX 원본과 각 PAK의 적용 전 길이를 기록합니다. 실패하면 프로그램이 자동으로 PAK를 원래 길이로 되돌리고 IDX를 복원합니다.
