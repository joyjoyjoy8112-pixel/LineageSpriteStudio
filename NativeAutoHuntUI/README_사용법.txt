AUTOHUNT NATIVE UI V1

목적
- 랭킹창/HighRankUI.xml을 더 이상 재활용하지 않습니다.
- 독립된 Windows 네이티브 자동사냥 설정창을 별도 EXE로 컴파일한 테스트 버전입니다.
- 게임(mjlin.bin) 위에 자동으로 중앙 배치됩니다.
- 서버의 기존 자동사냥 API(http://127.0.0.1:18081/autohunt/api)에 직접 연결합니다.

지원 기능
- 접속 캐릭터 목록 로드
- 사냥터 이름 선택
- 물약은 코드번호 없이 아이템 이름만 표시
- 물약 사용 HP / 귀환 HP / 복귀 HP
- 자동 귀환 / 자동 상점
- 공격 / 버프 / 방어 스킬 사용 여부
- 기본값 / 저장 / 자동사냥 시작 / 중지
- 서버 상태 표시

현재 제한
- 공격/버프/방어 '스킬 이름 선택'은 서버 API에 실제 스킬 ID 저장 필드가 아직 없어 '자동 선택' 표시만 합니다.
- 아직 mjlin.bin 내부 AUTO 버튼과 직접 연결하지 않았습니다. V1은 독립창 자체와 서버 연동을 먼저 검증합니다.

사용
1. 서버를 실행합니다.
2. 게임에 접속합니다.
3. AutoHuntSettingsUI.exe를 실행합니다.
4. 창이 게임 화면 중앙에 뜹니다.
5. 저장/시작/중지를 테스트합니다.

다음 단계
- V1 창이 정상 작동하면 게임 AUTO 버튼 또는 클라이언트 이벤트에서 이 EXE를 호출/토글하도록 연결합니다.
