AUTO 1~20 / 29999 이미지 + UI 숫자 동시 진단 패처

목적
- 이전 1~20 동시진단팩에서 체크무늬로 보였던 새 숫자 PNG를 사용하지 않습니다.
- 20개 버튼 모두 클라이언트 기존 이미지 ID 29999를 사용합니다.
- 버튼 바로 아래 숫자 1~20은 새 PNG가 아니라 클라이언트 UI 텍스트로 표시합니다.
- 기존 1~20 버튼의 서로 다른 Window/Control/부모/MouseEvent 방식은 그대로 유지합니다.

적용 순서
1. 게임과 접속기를 완전히 종료합니다.
2. 먼저 기존 'AUTO_1~20_게임화면_동시진단팩'이 적용된 상태여야 합니다.
3. 이 ZIP의 AUTO_DIAG20_PATCH.ps1 과 apply_auto_diag20.bat 두 파일을 UI.idx/UI.pak이 있는 리니지 클라이언트 폴더에 복사합니다.
4. apply_auto_diag20.bat 를 더블클릭합니다.
5. 완료 메시지가 나오면 게임을 실행합니다.

패처가 자동으로 하는 일
- UI.idx / UI.pak 백업
- MainButtonUI.xml 복호화
- 1~20 진단 버튼 20개 자동 탐색
- 모든 테스트 버튼 이미지 -> 29999;1
- 각 이미지 밑에 1~20 UI 글자 추가
- 마우스를 올렸을 때 TEST 1 ~ TEST 20 툴팁도 표시
- MainButtonUI.xml 재암호화 후 UI.pak/idx 갱신
- AUTO_DIAG20_적용결과.txt 생성

테스트 후 알려줄 내용
보이는 번호: 예) 5, 7, 9
클릭 결과:
5 = 반응 없음
7 = 행동창
9 = 자동사냥 설정창

복구
클라이언트 폴더에 자동 생성되는 AUTO_DIAG20_BACKUP_날짜시간 폴더의 UI.idx/UI.pak을 원래 위치로 복사하면 됩니다.

중요
- 서버 JAR, Navicat, Data.pak, Image00.pak은 이번 패치에서 건드리지 않습니다.
- 이 패처는 UI.idx/UI.pak 두 파일만 수정합니다.
