Lineage Client Inspector V2.7

[파일명 자연 숫자 정렬]
- 문자열 순서가 아니라 숫자 순서를 인식
- 예:
  61-0.spr
  61-1.spr
  61-2.spr
  ...
  61-9.spr
  61-10.spr
  61-11.spr
- 검색 결과와 전체 목록 모두 파일명 기준 자연 정렬
- 같은 파일명일 때 경로/위치로 추가 정렬

[SPR 프레임 자동 재생]
- SPR 파일을 선택하면 프레임 0부터 자동 재생 시작
- 기본 재생 간격 약 120ms
- 마지막 프레임 뒤에는 0번으로 돌아가 반복 재생
- '정지 ■' 버튼으로 멈춤
- '자동 ▶' 버튼으로 다시 시작
- 기존 프레임 번호 직접 선택 기능 유지
- 다른 파일을 선택하면 자동 재생 자동 정지

[기존 검색 개선 유지]
- 61- 검색은 파일명이 61-로 시작하는 것만 검색
- ***61- / abc61- 같은 앞문자 포함 파일 제외
- 숫자- 형태는 SPR/GFX 접두어 검색 모드

[기존 기능 유지]
- 클라 + 서버 + Navicat DB 통합 검색
- 검색 위치 실시간 표시
- 원본 수정/복원
- Java 단일 컴파일
- 서버 전체 컴파일 + JAR 생성
