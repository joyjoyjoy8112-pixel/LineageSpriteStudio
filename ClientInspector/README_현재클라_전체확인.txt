Lineage Client Inspector V2.8

[선택 원본 추출]
- 상단 '선택 추출' 버튼
- 실제 파일 / PAK 내부 파일 / SPR / 이미지 등 현재 선택 항목의 원본 바이트를 추출
- 저장 위치:
  프로그램 실행 폴더\Extracted
- 같은 이름이 이미 있으면 _1, _2 식으로 자동 이름 변경
- 추출 완료 후 정확한 전체 경로를 메시지와 상태바에 표시
- '추출 폴더 열기' 버튼으로 바로 열기

[이미지 원본/수정본 2분할 비교]
표준 PNG/BMP/JPEG/GIF/ICO 등의 이미지를 선택하면 오른쪽 화면을 2개로 분할:
- 왼쪽: 원본
- 오른쪽: 수정본

[원본 이미지 정보]
원본 화면 아래에 다음 정보 표시:
- 가로 × 세로 픽셀 크기
- 이미지 포맷
- PixelFormat
- 원본 바이트 크기
- DPI
- 실제 파일 경로 또는 PAK/IDX 위치

[수정 이미지]
- 수정 이미지 불러오기
- 원본과 수정본 크기 일치 여부 표시
- 수정본 크기 / 포맷 / PixelFormat / 용량 표시
- 수정본 초기화: 원본 이미지로 되돌림

[간단 색상 테스트]
- '색상 테스트' 버튼
- Windows 색상 선택창에서 테스트 색상 선택
- 원본 알파(투명도)를 유지하면서 선택 색상을 약 42% 혼합
- 오른쪽 수정본에 즉시 표시
- 이 단계에서는 원본 파일을 건드리지 않음

[수정본 등록]
실제 파일:
- 원본과 같은 가로/세로 크기만 허용
- 원본 포맷에 맞춰 다시 인코딩
- <원본>.image.bak 최초 백업 후 교체

PAK 내부:
- 원본 데이터가 표준 이미지여야 함
- 비암호화 LEGACY28 IDX/PAK만 안전 재등록
- 적용 전 IDX/PAK 모두 .imagebak_날짜시간 백업
- 새 이미지 바이트로 PAK 재묶기 및 IDX offset/size 갱신
- _EXT/_IDX/DES/기타 미검증 형식은 직접 등록 차단

[안전 제한]
- 원본 이미지와 수정 이미지의 가로/세로가 다르면 등록 차단
- 표준 이미지로 해석할 수 없는 Lineage 전용 이미지 포맷은 억지로 PNG로 덮어쓰지 않음
- ICO 재인코딩은 현재 차단
- 실패 시 원본을 가능한 한 건드리지 않도록 적용 전 검증/백업

[기존 기능 유지]
- 자연 숫자 정렬
- 61- 접두어 검색
- SPR 프레임 자동 재생
- 클라 + 서버 + Navicat DB 통합 검색
- 원본 텍스트 수정/복원
- Java 단일/전체 컴파일
