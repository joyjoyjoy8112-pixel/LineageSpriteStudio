Lineage Client Inspector V2.4

[검색 위치 실시간 표시]
하단 상태바에 아래 3개 영역을 각각 표시합니다.
- 클라: 대기 / 검색중 / 완료 N건 / 미선택
- 서버: 대기 / 검색중 / 완료 N건 / 미선택
- DB: 대기 / 검색중 / 완료 N건 / 미선택

[통합 검색 진행]
검색 순서를 영역별로 분리해 현재 위치를 정확하게 표시합니다.
1. Navicat/DB 백업
2. 서버팩 폴더
3. 클라이언트 + IDX/PAK 내부

검색 중 예:
DB: 검색중... (3)
서버: 대기
클라: 대기

검색 완료 예:
DB: 완료 3건 | 서버: 완료 5건 | 클라: 완료 7건

검색 결과 상태 문구에도
클라 N / 서버 N / DB N
형태로 영역별 발견 건수를 표시합니다.

[기존 기능 유지]
- 정확 검색
- 클라이언트 + PAK + DB + 서버팩 폴더 통합 검색
- 서버팩 내부 PSC 검색
- 파일/내부경로 우클릭 이름 복사
- 원본 파일 수정
- Ctrl+S 저장 / Esc 취소
- .bak 자동 백업
- 원본 복원(.bak)
- 복원 직전 .before_restore 백업
