Lineage Client Inspector V2.2

[파일/내부경로 우클릭]
- '파일/내부경로' 칸에서 마우스 우클릭
- 이름 복사
  예: src\...\AutoHuntController.java → AutoHuntController.java만 클립보드 복사
- 원본 파일 수정
  * 클라이언트 실제 텍스트 파일
  * 서버팩 폴더 실제 텍스트 파일
  * 직접 선택한 SQL/텍스트 DB 백업
  위 항목은 오른쪽 창에서 직접 편집 가능

[원본 편집]
- Ctrl+S : 원본 파일에 저장
- Esc : 수정 취소
- 최초 저장 시 같은 위치에 .bak 백업 자동 생성
- UTF-8 BOM / UTF-16 LE/BE / UTF-8 / CP949 인코딩을 가능한 범위에서 유지
- 편집 중에는 왼쪽 목록을 잠가 다른 파일로 실수로 이동하지 않도록 처리
- 20MB 이하의 텍스트 원본만 직접 편집 허용

[직접 수정하지 않는 항목]
- PAK 내부 파일
- PSC 내부/압축 결과
- .class / .jar / .exe / .dll 등 바이너리
이 항목들은 원본 포맷 손상 방지를 위해 직접 저장하지 않습니다.

[기존 기능 유지]
- 클라이언트 + IDX/PAK + DB + 서버팩 폴더 통합 검색
- 서버팩 폴더 재귀 검색
- 서버팩 내부 zlib PSC 실제값 검색
- 정확 숫자 경계 검색
- PNG/SPR/HTML/텍스트 미리보기
