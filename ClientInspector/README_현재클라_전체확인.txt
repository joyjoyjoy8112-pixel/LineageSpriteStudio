Lineage Client Inspector V2.3

[파일/내부경로 우클릭]
- 이름 복사
- 원본 파일 수정
- 원본 복원 (.bak)

[원본 수정]
- 클라이언트 실제 텍스트 파일
- 서버팩 폴더 실제 텍스트 파일
- 직접 선택한 SQL/텍스트 DB 백업
- Ctrl+S 저장
- Esc 취소
- 최초 저장 시 같은 위치에 <원본파일>.bak 자동 생성
- UTF-8 BOM / UTF-16 LE/BE / UTF-8 / CP949 인코딩 유지
- 20MB 이하 텍스트 파일만 직접 편집

[원본 복원]
- .bak가 존재하는 파일만 '원본 복원 (.bak)' 메뉴 활성화
- 복원 확인 후 .bak 내용을 원본 파일에 적용
- 복원 직전 현재 파일은 <원본파일>.before_restore 로 자동 보관
- 복원 후 파일 크기/검색용 텍스트/미리보기 갱신

[직접 수정 제외]
- PAK 내부
- PSC 내부/압축 검색 결과
- .class / .jar / .exe / .dll 등 바이너리

[기존 기능 유지]
- 클라이언트 + IDX/PAK + DB + 서버팩 폴더 통합 검색
- 서버팩 폴더 재귀 검색
- 서버팩 내부 zlib PSC 실제값 검색
- 정확 숫자 경계 검색
- PNG/SPR/HTML/텍스트 미리보기
