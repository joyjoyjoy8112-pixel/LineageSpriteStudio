사용 방법
1. 게임/접속기/서버를 종료합니다.
2. 이 패치팩을 아무 폴더에 압축 해제합니다.
3. payload\server 아래에는 서버에 적용할 파일,
   payload\client 아래에는 클라이언트에 적용할 파일이 들어갑니다.
4. UPDATE_AUTOHUNT.bat 하나만 실행하면 두 위치를 자동으로 업데이트합니다.

자동 기능
- 정확한 대상 경로 확인
- 기존 파일 자동 백업
- 상대 경로 그대로 복사
- SHA256 해시 검증
- 패치 버전 기록
- 로그 저장
- 롤백 지원

복구
ROLLBACK_LAST_UPDATE.bat 실행.
각 대상 폴더의 _AUTOHUNT_PATCH_BACKUP 안에 있는 가장 최근 백업으로 복구합니다.

앞으로 자동사냥 설정창 패치는 이 형식의 payload만 바꿔서 배포하면 됩니다.
